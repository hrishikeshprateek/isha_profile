### Step 2: Submit to Google Search Console

#### A. Add Property (if not done)
1. Go to: https://search.google.com/search-console
2. Click "Add Property"
3. Choose "URL prefix"
4. Enter: `https://www.isharani.in`
5. Verify ownership using one of these methods:
   - **HTML file upload** (easiest)
   - **HTML tag** in `<head>`
   - **Google Analytics**
   - **DNS record**

#### B. Submit Sitemap
1. In Google Search Console, click "Sitemaps" in left menu
2. Enter: `sitemap.xml`
3. Click "Submit"
4. ✅ Wait 24-48 hours for Google to process

### Step 3: Request Indexing for Key Pages

Manually request indexing for these important pages:

1. **Homepage**: `https://www.isharani.in`
2. **Blog Page**: `https://www.isharani.in/blogs`
3. **Quotes Page**: `https://www.isharani.in/quotes`
4. **Your Latest Blog Post**: Copy URL from `/blogs`
5. **Your Latest Quote**: Copy URL from `/quotes`

**How to Request Indexing:**
1. In Search Console, go to "URL Inspection"
2. Paste the URL
3. Click "Request Indexing"
4. Repeat for each key page

## ⚠️ Common Issues & Fixes

### Issue: Pages not being indexed
**Solutions:**
1. Check robots.txt isn't blocking
2. Submit sitemap again
3. Request indexing manually
4. Check for crawl errors
5. Ensure content is high quality

### Issue: Low impressions
**Solutions:**
1. Publish more content
2. Optimize existing content
3. Build backlinks
4. Share on social media
5. Improve keyword targeting

### Issue: High impressions, low clicks
**Solutions:**
1. Improve title tags (more compelling)
2. Better meta descriptions
3. Add structured data
4. Improve content quality
